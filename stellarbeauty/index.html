Fundamentos

Princípios de Design

Cinco princípios guiam cada decisão visual e de interação no Stellar Beauty Design System.

01
Feminilidade Sofisticada
Cada elemento visual deve comunicar elegância sem afetação. Rosas terrosos, não pinks berrantes. Curvas generosas, não agressivas.
02
Tech Premium
A tecnologia é visível, mas nunca fria. Tipografia Geist traz modernidade; Poppins traz humanidade. O equilíbrio é a identidade.
03
Clean Impactante
Espaço em branco é ingrediente, não ausência. Cada elemento tem propósito. Menos, melhor, mais belo.
04
Acolhimento
Bordas arredondadas, paleta quente, feedbacks suaves. O sistema deve abraçar a usuária, nunca intimidar.
05
Consistência Total
Tokens centralizados, padrões documentados. O que funciona em uma tela funciona em todas. Zero surpresas para a usuária.

Regras

Regras de UI

Diretrizes obrigatórias para garantir consistência, acessibilidade e identidade visual em toda a interface.

Uso da Cor Primária

✓
Use --color-primary para CTAs e ações principais
✓
Use como cor de destaque em métricas e valores importantes
✓
Use para indicar item ativo na navegação lateral
!
Não use primário em mais de 2 elementos por viewport visível
!
Não use primário em fundos de grandes áreas — use --color-primary-xlight

Contrastes & Acessibilidade

✓
Texto escuro sobre fundos claros: relação mínima 4.5:1 (WCAG AA)
✓
Botões primários: sempre texto branco (contraste adequado)
✓
Focus rings visíveis em todos os elementos interativos
!
Não use cor como único indicador de estado — adicione texto ou ícone
!
Tamanho mínimo de fonte para corpo: 14px (--text-sm)

Aparência Premium

✓
Bordas sempre com --color-border (#D3CEC5) — nunca cinza genérico
✓
Sombras sutis com opacidade baixa, nunca sombras pretas pesadas
✓
Espaçamento generoso — prefira mais espaço a menos
✓
Transições suaves em todos os estados hover/focus

Consistência Tipográfica

✓
Geist exclusivo para títulos, labels, métricas e UI elementos de heading
✓
Poppins para todo texto corrido, formulários e conteúdo
!
Não misture pesos acima de 700 no Poppins em UI — use Geist 900
!
Letter-spacing negativo apenas em tamanhos acima de 24px
